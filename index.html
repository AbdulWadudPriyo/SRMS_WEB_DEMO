Time Complexity

01Insert
O(n)

Traverse until the correct roll-number position is found, then connect the new node.

02Search
O(n)

Visit nodes sequentially from HEAD until the target roll number is found.

03Delete
O(n)

Find the target node and bypass it by updating the previous node's next link.

04Space
O(n)

Each student requires one node, so memory grows linearly with the records.
