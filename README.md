# Student Record Management System — Web Demo

An attractive, responsive, database-free web interface for the 2024 Java Data Structures project.

## What this demo showcases

- Singly Linked List visualization
- Sorted insertion by roll number
- Animated sequential search traversal
- Node deletion
- Student record table
- LocalStorage persistence
- Dark / light mode
- Responsive mobile layout
- Complexity notes: Insert, Search, Delete, Space

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage
- No backend
- No database

## Run locally

No build tool is required.

1. Extract the folder.
2. Open `index.html` in a browser.

For best results, use VS Code + Live Server, or any simple static HTTP server.

## GitHub Pages

Upload this folder to your repository and enable GitHub Pages from the repository's Pages settings. Because this is a static site, no server/database is required.
